# راهنمای راه‌اندازی روی Cloudflare Pages

این پروژه یک سایت کاملاً استاتیک به‌همراه چند «Function» سمت سرور است (در پوشه‌ی `functions/`)
که روی Cloudflare Pages به‌صورت رایگان اجرا می‌شود. دیتابیس هم از **Cloudflare D1** استفاده می‌کند
(رایگان و بدون نیاز به سرور جداگانه).

## مرحله ۱ — ساخت دیتابیس D1

۱. وارد داشبورد Cloudflare شوید → از منوی سمت راست **Workers & Pages** → **D1** را باز کنید.
۲. روی **Create database** بزنید، یک اسم بگذارید (مثلاً `blog-db`) و بسازید.
۳. وارد همان دیتابیس شوید → تب **Console** را باز کنید.
۴. محتوای فایل `schema.sql` (همین پوشه) را کپی و در آن Console اجرا کنید (Run).
   این کار جدول `pages` را می‌سازد.

## مرحله ۲ — ساخت پروژه‌ی Pages با Drag & Drop

۱. در داشبورد Cloudflare → **Workers & Pages** → **Create application** → تب **Pages** →
   **Upload assets** (همان روش drag & drop).
۲. یک اسم پروژه انتخاب کنید.
۳. کل محتوای این پوشه (شامل `index.html`، `style.css`، `page.html`، پوشه‌ی `admin/`،
   پوشه‌ی `assets/` و پوشه‌ی `functions/`) را به‌صورت یک‌جا درگ کنید و آپلود را تمام کنید.
   (پوشه‌ی `functions` هم باید داخل همین آپلود باشد تا API کار کند.)

## مرحله ۳ — اتصال دیتابیس به پروژه

۱. وارد پروژه‌ی Pages که ساختید شوید → تب **Settings** → **Functions** →
   بخش **D1 database bindings**.
۲. یک binding جدید بسازید با نام دقیق `DB` و دیتابیسی که در مرحله‌ی ۱ ساختید را انتخاب کنید.

## مرحله ۴ — تنظیم رمز عبور ادمین

۱. همان‌جا در **Settings** → **Environment variables** دو متغیر بسازید (نوع را روی
   **Secret** بگذارید تا در داشبورد نمایش داده نشود):

   - `ADMIN_PASSWORD` → همان رمزی که می‌خواهید برای ورود به `/admin` استفاده کنید.
   - `SESSION_SECRET` → یک رشته‌ی تصادفیِ بلند و دلخواه (فقط برای امضای امن نشست ورود؛
     خودتان لازم نیست آن را به‌خاطر بسپارید).

۲. بعد از افزودن این متغیرها، یک بار پروژه را دوباره Deploy کنید (از تب **Deployments** →
   روی آخرین دیپلوی → **Retry deployment**) تا متغیرها اعمال شوند.

## استفاده

- سایت عمومی: آدرس اصلی پروژه (یا دامنه‌ی سفارشی‌ای که به آن وصل می‌کنید)
- پنل مدیریت: همان آدرس + `/admin` — رمز عبوری که در `ADMIN_PASSWORD` گذاشتید را وارد کنید.

## بعداً

- برای وصل کردن یک دامنه‌ی اختصاصی: تب **Custom domains** در همان پروژه‌ی Pages.
- برای هر تغییر آینده در کد: کافی‌ست دوباره پوشه‌ی به‌روزشده را در تب **Deployments** →
  **Create deployment** درگ‌ودراپ کنید.
