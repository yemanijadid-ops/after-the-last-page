# راه‌اندازی از طریق گیت‌هاب (Cloudflare Workers)

این نسخه برای همون روشی ساخته شده که داری توی Cloudflare انجام می‌دی: وصل‌کردن مخزن گیت‌هاب و
دیپلوی با Wrangler (نه آپلود مستقیم فایل).

## مرحله ۱ — ساخت دیتابیس D1

۱. در داشبورد Cloudflare → **Storage & Databases** → **D1** → **Create database**.
۲. اسمش رو `blog-db` بذار (یا هر اسم دیگه، فقط بعداً باید توی تنظیمات واردش کنی).
۳. وارد همون دیتابیس شو → تب **Console** → محتوای فایل `schema.sql` رو کپی و اجرا (Run) کن.
۴. توی صفحه‌ی همون دیتابیس، یک مقدار به اسم **Database ID** می‌بینی — آن را کپی کن
   (یک رشته‌ی طولانی شبیه UUID است).

## مرحله ۲ — وارد کردن Database ID توی کد

۱. برو توی مخزن گیت‌هابت → فایل `wrangler.jsonc` را باز کن → روی آیکن مداد (Edit) بزن.
۲. عبارت `PUT-YOUR-DATABASE-ID-HERE` را با همان Database ID که کپی کردی جایگزین کن.
۳. پایین صفحه روی **Commit changes** بزن.

## مرحله ۳ — ادامه‌ی ویزارد Cloudflare

برگرد به همون صفحه‌ی «Create an app» که مخزن گیت‌هابت را انتخاب کرده بودی:

- **Build command**: خالی بذار.
- **Deploy command**: همون پیش‌فرض `npx wrangler deploy` را نگه‌دار.
- روی **Deploy** بزن.

## مرحله ۴ — تنظیم رمز عبور ادمین

بعد از اولین دیپلوی موفق:

۱. وارد پروژه‌ی Worker که ساخته شد بشو → تب **Settings** → **Variables and Secrets**.
۲. دو مقدار بساز (نوع را روی **Secret** بگذار):
   - `ADMIN_PASSWORD` → رمزی که می‌خوای برای ورود به `/admin` استفاده کنی.
   - `SESSION_SECRET` → یک رشته‌ی تصادفی و دلخواه (هر چیزی، فقط طولانی و غیرقابل‌حدس).
۳. اگر بعد از افزودن این مقادیر صفحه‌ی ورود هنوز خطا داد، از تب **Deployments** یک بار
   **Retry deployment** بزن.

## استفاده

- سایت: آدرس Worker (چیزی شبیه `my-weblogggggg.<account>.workers.dev`) یا دامنه‌ی سفارشی
- پنل مدیریت: همان آدرس + `/admin`

## بعداً

- هر تغییری در کد که روی گیت‌هاب commit کنی، Cloudflare خودش دوباره دیپلویش می‌کنه.
- برای وصل‌کردن دامنه‌ی اختصاصی: تب **Settings → Domains & Routes** در همین پروژه.
